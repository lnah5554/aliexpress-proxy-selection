## AliExpress 代理配置时要注意什么？

### 先确认代理格式和认证方式

购买后，代理服务一般会提供 IP、端口、用户名和密码，具体格式以账户后台显示为准。接入采集工具或浏览器自动化环境时，要确认工具支持的协议类型，例如 HTTP、HTTPS 或 SOCKS5。

不要把带认证信息的代理配置直接写进公开代码仓库，也不要把完整代理链接发到团队公共聊天频道。代理凭据一旦泄露，别人可能消耗你的资源，甚至触发异常访问。

### 控制每个 IP 的并发量

代理池的基本思路不是“IP 越多，请求越快”，而是把任务分配得更均匀。建议为每个 IP 设置并发上限，并根据目标页面响应时间动态调整。

常见的控制方式包括：

- 为每个 IP 设置请求间隔；
- 限制单个 IP 的并发连接数；
- 对 429、403 和验证码响应设置退避；
- 对失败请求采用逐步延迟重试；
- 缓存短时间内不会变化的数据；
- 记录每个 IP 的成功率和响应时间。

这样做不仅更稳定，也能避免因为重复请求导致带宽和代理资源浪费。

### 不要忽略地区、语言和货币设置

如果你要研究美国用户看到的商品信息，除了使用美国代理，还要统一浏览器语言、货币、配送地址和页面环境。否则，采集到的价格可能混合不同地区因素，后续分析会变得困难。

代理位置只能改变网络出口。它不能自动改变账号地区、付款信息或平台为登录用户保存的偏好。

### 将代理故障和页面变化分开判断

抓取失败不一定是代理问题。还可能是：

- 页面结构发生变化；
- 商品已下架；
- 请求超时；
- 页面需要额外验证；
- 账号权限变化；
- 目标站点临时维护；
- 程序解析器无法识别新字段。

如果不记录状态码、响应时间、页面标题和错误类型，就很难判断到底是 IP 无效，还是程序本身出了问题。
